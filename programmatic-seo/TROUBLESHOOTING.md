# 🔧 Troubleshooting Guide

Common issues and solutions for Programmatic SEO Plugin.

---

## ❌ Error: "Failed to save template"

### Possible Causes & Solutions

#### 1. Unknown column 'description' in INSERT INTO

**Cause:** Old database schema missing new columns

**Solution:**
```
1. Go to Plugins page
2. Click "Deactivate" on Programmatic SEO
3. Click "Activate" again
4. ✅ Database auto-updates
```

**What happens:** Migration script adds missing columns automatically.

**Verify:** Check debug.log for:
```
PSEO: Added description column to templates table
PSEO: Added slug_pattern column to templates table
```

---

#### 2. Template variables {{}} getting stripped

**Cause:** Already fixed in v1.0.2+

**Solution:** Update to latest version

**Technical:** Plugin now uses smart sanitization that preserves `{{variables}}`

---

#### 3. Nonce verification failed

**Cause:** Session timeout or cache issues

**Solution:**
```
1. Clear browser cache
2. Refresh the page
3. Try saving again
```

---

#### 4. Unauthorized error

**Cause:** User doesn't have admin permissions

**Solution:**
```
1. Make sure you're logged in as Administrator
2. Or user must have 'manage_options' capability
```

## ❌ Error: "Failed to import data"

### Common Issues

#### Invalid file type
- Only CSV and JSON supported
- Check file extension

#### Encoding issues
- File must be UTF-8 encoded
- Excel CSV may use wrong encoding

**Fix:**
```
1. Open CSV in text editor
2. Save As → UTF-8 encoding
3. Upload again
```

#### Empty or malformed file
- CSV must have header row
- JSON must be valid array

## ❌ Error: "Failed to generate pages"

### Template/Data mismatch

**Problem:** Variables in template don't match CSV columns

**Example:**
```
Template: "Service {{service}} in {{city}}"
CSV columns: service_name, location  ❌

Fix CSV to:
CSV columns: service, city  ✅
```

**Solution:**
1. Check template variables
2. Match CSV column names exactly
3. Case-sensitive!

---

### Memory limit exceeded

**Symptom:** Generation stops halfway

**Solution:**

Edit `wp-config.php`:
```php
define('WP_MEMORY_LIMIT', '256M');
```

Or generate in smaller batches:
```
Instead of 1000 pages → Do 100 at a time
```

---

### Timeout on large batches

**Symptom:** "Maximum execution time exceeded"

**Solution:**

Edit `.htaccess`:
```apache
php_value max_execution_time 300
```

Or use smaller batches.

---

## ❌ Pages generated but empty

### Check these:

1. **Variables match data:**
   ```
   Template: {{city}}
   Data has: city  ✅
   ```

2. **Data not empty:**
   ```csv
   city,service
   Hà Nội,Web Dev  ✅
   ,,  ❌ (empty row)
   ```

3. **Encoding correct:**
   - Use UTF-8
   - Not Windows-1252 or other

## ❌ SEO features not working

### Meta tags missing

**Check:**
1. Template has `meta_description_template` filled
2. Generated page has `_pseo_meta_description` in post meta
3. Theme's `<head>` section not overriding

**Debug:**
```php
// Add to theme's functions.php temporarily
add_action('wp_head', function() {
    global $post;
    $meta = get_post_meta($post->ID, '_pseo_meta_description', true);
    echo "<!-- PSEO Meta: $meta -->";
});
```

---

### Schema markup not showing

**Verify:**
1. Page is generated by plugin (check post meta)
2. View page source, search for `application/ld+json`
3. Validate at: https://validator.schema.org/

## 🔍 Enable Debug Mode

### WordPress Debug

Edit `wp-config.php`:
```php
define('WP_DEBUG', true);
define('WP_DEBUG_LOG', true);
define('WP_DEBUG_DISPLAY', false);
```

Check log at: `wp-content/debug.log`

### Plugin Specific Logs

Search for `PSEO:` in debug.log:
```bash
tail -f wp-content/debug.log | grep PSEO
```

You'll see:
```
PSEO: Attempting to save template...
PSEO: Template data prepared...
PSEO: Save failed - [error details]
```

## 🗑️ Clean Reinstall

**If all else fails:**

### Backup first!
```
1. Export all templates (Export button)
2. Backup database (phpMyAdmin)
3. Download uploaded CSV files
```

### Clean install:
```
1. Deactivate plugin
2. Delete plugin
3. Reinstall from fresh download
4. Activate
5. Import templates back
```

## 📊 Database Issues

### Tables not created

**Check:**
```sql
SHOW TABLES LIKE 'wp_pseo_%';
```

Should show:
- `wp_pseo_templates`
- `wp_pseo_data_sources`
- `wp_pseo_generated_pages`

**Fix:**
```
1. Deactivate plugin
2. Reactivate
3. Check again
```

---

### Repair tables

If tables corrupted:
```sql
REPAIR TABLE wp_pseo_templates;
REPAIR TABLE wp_pseo_data_sources;
REPAIR TABLE wp_pseo_generated_pages;
```

## 🚀 Performance Issues

### Slow admin pages

**Solutions:**
1. Limit templates shown per page
2. Archive old templates
3. Increase PHP memory limit

### Slow generation

**Solutions:**
1. Use smaller batches (50-100 pages)
2. Increase max_execution_time
3. Disable other plugins during generation
