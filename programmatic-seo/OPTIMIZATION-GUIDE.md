# Programmatic SEO - Plugin Optimization & Installation Guide

## ✅ Pre-Installation Checklist

### System Requirements
- **WordPress**: 5.0 or higher
- **PHP**: 7.2 or higher (7.4+ recommended)
- **MySQL**: 5.6 or higher
- **Database**: At least 10MB free space

### Required PHP Extensions
- `mysqli` or `mysql` (for database)
- `json` (for template import/export)
- `gd` (optional, for image processing)
- `curl` (optional, for external API calls)

### Recommended Server Configuration
```ini
; php.ini
upload_max_filesize = 10M
post_max_size = 10M
max_execution_time = 300
memory_limit = 256M
max_input_vars = 10000

; MySQL
innodb_buffer_pool_size = 256M
max_allowed_packet = 16M
```

## 🚀 Installation Steps

### Step 1: Download Plugin
```bash
# Clone from GitHub
git clone https://github.com/tootranmmo/programmaticSEOs.git
cd programmaticSEOs/programmatic-seo

# Or download as ZIP and extract to:
# /wp-content/plugins/programmatic-seo/
```

### Step 2: Upload to WordPress
Option A: Manual FTP Upload
```bash
1. Extract programmatic-seo folder
2. Upload to /wp-content/plugins/
3. Set folder permissions: 755
4. Set file permissions: 644
```

Option B: WordPress Admin Upload
```
1. Go to Plugins → Add New → Upload Plugin
2. Select programmatic-seo.zip
3. Click "Install Now"
4. Click "Activate Plugin"
```

### Step 3: Verify Installation
After activation, verify:
- ✅ Plugin appears in WordPress admin menu
- ✅ Database tables created (check wp_pseo_* tables)
- ✅ Upload directory created: `/wp-content/uploads/programmatic-seo/`
- ✅ No PHP errors in debug.log

### Step 4: Initial Setup
1. Go to **Programmatic SEO** → **Dashboard**
2. Review system statistics
3. Create first template
4. Import sample data
5. Generate test pages

## 🔧 Optimization Tips

### Performance Optimization

#### 1. Batch Page Generation
```
Instead of:  Generate 1000 pages at once
Do this:     Generate in batches of 100-200
Benefit:     Avoid timeouts and memory issues
```

#### 2. Database Optimization
```sql
-- Optimize tables after bulk generation
OPTIMIZE TABLE wp_pseo_templates;
OPTIMIZE TABLE wp_pseo_data_sources;
OPTIMIZE TABLE wp_pseo_generated_pages;
OPTIMIZE TABLE wp_posts;
OPTIMIZE TABLE wp_postmeta;
```

#### 3. Caching Configuration
```php
// Add to wp-config.php
define('WP_CACHE', true);
define('AUTOSAVE_INTERVAL', 60);
define('WP_POST_REVISIONS', 3);
```

#### 4. Template Best Practices
- ✅ Use short, descriptive variable names
- ✅ Limit template content to 5000 characters
- ✅ Test with 10-20 rows before bulk generation
- ✅ Preview templates before generating

## 🐛 Troubleshooting

### Issue: Plugin Doesn't Activate
**Solution**:
```bash
1. Check PHP version: php -v
2. Check error log: tail -f wp-content/debug.log
3. Verify file permissions: chmod 755 programmatic-seo/
4. Try deactivate/reactivate
```

### Issue: Database Error - Unknown Column
**Solution**:
```
1. Deactivate plugin
2. Reactivate plugin (runs migration automatically)
3. Check DATABASE-UPDATE.md
4. Clear browser cache
```

### Issue: Import CSV Fails
**Solution**:
```
1. Verify CSV encoding is UTF-8
2. Ensure first row has column headers
3. Check file size < upload_max_filesize
4. Try with sample-data.csv first
```

### Issue: Page Generation Timeout
**Solution**:
```
1. Reduce batch size (generate 50-100 at a time)
2. Increase PHP max_execution_time
3. Increase memory_limit to 512M
4. Check for other plugins consuming resources
```

### Issue: SEO Tags Not Appearing
**Solution**:
```
1. Verify page was generated by plugin (check post meta)
2. Check theme's wp_head() function is called
3. View page source to see meta tags
4. Check wp_kses_post() not filtering tags
```

## 📊 Database Schema

### Tables Created

#### wp_pseo_templates
```sql
id              - Template ID
name            - Template name
description     - Description
title_template  - Title with {{variables}}
content_template - Content with {{variables}}
meta_description_template - Meta description template
slug_pattern    - URL slug pattern
post_type       - WordPress post type (page/post/custom)
status          - active/inactive
variables       - Detected variables JSON
created_at      - Creation timestamp
updated_at      - Last update timestamp
```

#### wp_pseo_data_sources
```sql
id              - Source ID
name            - Source name
file_name       - Original file name
file_path       - Upload path
file_type       - CSV/JSON
total_rows      - Number of data rows
columns         - Column names JSON
status          - active/inactive
created_at      - Creation timestamp
```

#### wp_pseo_generated_pages
```sql
id              - Record ID
post_id         - WordPress post ID
template_id     - Template used
data_source_id  - Data source used
data_row_index  - Row index from source
views           - Page view count
clicks          - Analytics clicks
created_at      - Creation timestamp
```

## 🚨 Common Errors & Solutions

| Error | Cause | Solution |
|-------|-------|----------|
| "Unknown column 'description'" | Old DB schema | Reactivate plugin |
| "{{variables}} disappears" | wp_kses_post filtering | Update to 1.0.2+ |
| "Fatal error: Class not found" | Missing file | Verify all files uploaded |
| "Permission denied" | Bad folder permissions | chmod 755 plugin folder |
| "Maximum execution time exceeded" | Too many pages | Reduce batch size |
| "Memory exhausted" | Large data import | Increase memory_limit |
